Política de privacidade

Modelo para revisão. Este texto descreve como o site funciona hoje e deve ser revisado por um advogado antes da publicação definitiva. Os campos entre colchetes precisam ser preenchidos.

Última atualização: 28 de outubro de 2026

Quem é responsável

Este site é mantido pela No Fear [razão social a preencher], inscrita no CNPJ [a preencher]. Para qualquer assunto sobre privacidade, escreva para contato@nofear.com.br.

O que o site coleta

O site não tem formulários, não pede cadastro e não usa cookies, pixels de anúncio nem ferramentas de análise de visitas. As fontes e os ícones são carregados do próprio site, sem chamadas a serviços de terceiros.

Hospedagem

O site é hospedado no GitHub Pages. Como qualquer servidor, o GitHub pode registrar dados técnicos da visita, como endereço IP e navegador, para segurança e funcionamento do serviço. Esse tratamento segue a política de privacidade do próprio GitHub.

Contato pelo WhatsApp e por email

Os botões de WhatsApp abrem uma conversa com uma mensagem inicial já escrita, que você pode editar ou apagar antes de enviar. A partir daí, a conversa acontece no WhatsApp, serviço da Meta, sujeito às regras dele. O que você nos enviar por WhatsApp ou email é usado apenas para responder ao seu contato e preparar uma proposta, e não é vendido nem repassado para fins de publicidade.

Por quanto tempo guardamos

Mensagens de contato ficam guardadas pelo tempo necessário para a conversa comercial e para obrigações legais. [Prazo a definir.]

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir acesso, correção, exclusão ou informações sobre o uso dos seus dados. Basta escrever para contato@nofear.com.br.

Dados dos sistemas que desenvolvemos

Esta política vale apenas para o site. O tratamento de dados de pacientes nos sistemas, chatbots e servidores MCP que construímos é definido em contrato com cada clínica.

Mudanças nesta política

Se esta política mudar, a data no topo da página será atualizada.
